# Security

This pack gives security guidance, mostly about Row Level Security and tenant isolation, so a mistake in a skill can become a mistake in someone's production database. If you find advice here that is wrong in a way that could expose data, or a check that passes when it should fail, please report it privately rather than in a public issue: email security@updates.tanfust.com with the skill name, the affected section, and a minimal reproduction if you have one. You will get an acknowledgement within 72 hours and a fix or a written explanation within 14 days, and the fix will be noted in `CHANGELOG.md` with credit unless you ask otherwise. Secrets or customer data accidentally committed to this repo fall under the same address. Vulnerabilities in Supabase, Paddle, RevenueCat or any other vendor referenced by a skill should go to that vendor's own security programme.
